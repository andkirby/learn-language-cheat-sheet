Type voices

Two voices, one rule: Russian explanation text uses --font-ui (system sans); any element carrying the studied language is marked with a lang attribute (set by markTargetLang in each page) and rendered in --font-study (system serif). The serif is the “this is the language you are learning” signal — a textbook convention. No external fonts.

Marking rule (page JS): whole .example/.answer/.table-scroll containers are marked when they contain no Cyrillic; otherwise bold in .example/.answer, italics in .detail-block, and formula slots without Cyrillic are marked individually.

Color tokens

Semantic roles only — raw hex lives exclusively in the :root blocks of base.css. Every light value ships with its dark twin (≥ 4.5:1 for text). Toggle the theme in the topbar to check both.

Tappable chips

The only button styles on language pages. Open a DETAILS dialog or reveal an answer. Visual min-height 40px with ::after hit-area expansion to ≥ 46px — density without missed taps.

.tap primary · .tap.neutral secondary · .tap.case 44px case tile. No other button styles.

Bottom-sheet dialog

One shared #detailDialog per page; content set from the page’s DETAILS object. Closes via ×, Escape and backdrop tap. Focus is trapped natively by showModal().

Bottom nav & views

Five view destinations; the selected view is the nav truth (aria-current), no scrollspy. Sections carry data-view; legacy anchors open the section’s view first. While body.searching is set, the intro line hides and matching sections from every view are shown stacked. Shown here as a static specimen (.sg-nav override).

Class roles

Classes are semantic — named by role, not appearance. The small utility tail (.muted, .tiny, .cards.two/.three, td.hot) is deliberate and documented here; if a name stops matching its role, rename it in base.css and every page in the same commit.

Not in base.css: the landing hero and .lang-card live inline in index.html (hub-only components), and each language page owns nothing beyond the shared stylesheet.

Do / don’t

Do

· New color → semantic token in :root first, light + dark together.

· Keep touch targets ≥ 44px effective (hit-area padding allowed).

· Depth goes into DETAILS dialogs; first layer stays one screen.

· Mark target-language text with lang — it drives pronunciation and the study voice.

· Bump CACHE_VERSION after any asset change; keep anchors stable.

Don’t

· Raw hex in component rules or page-local overrides of base.css.

· user-scalable=no or unconditional maximum-scale=1.

· Information by color alone (pair td.hot-style cues with weight/text).

· New button styles beside .tap, or hero/jump-chip style navigation.

· Behaviors that die without JS — noscript must still read the whole deck.
